## 3. 初回の警告と判断

### 3.1 調整後の値が API の値と一致しない行（初回 WARN → 原因特定）

- 自分で計算し直した調整後終値と、API の `AdjC` を比べると、97.11% の行は完全に一致した（差 1e-6 以内）
- 一致しなかった 146,660行は、**すべて差が 0.05円以内**。差が 0.05円を超える行は 0件
- 一致しなかった行の API の値は、**すべて 0.1円単位**だった

**判断：** API は調整後の価格を 0.1円単位に丸めている。差はこの丸めによるもので、調整の計算誤りではない。計算方向（過去の値を最終日の株数基準に合わせる）も API と一致している。**データの修正は不要。** このプロジェクトは丸める前の値を使う（シグナルは比率で判定するため、丸めの影響を受けない方がよい）。

差が最も大きかった例：株価4〜5円の低位株（65740）で、4.65円 と 4.70円（相対 1.06%）。

### 3.2 分割では説明できない ±50%超の値動き（初回 WARN → 分類）

145件（101銘柄）を1件ずつ分類した。

| 分類 | 件数 | 意味 |
|---|---|---|
| 購入対象外の銘柄 | 28 | 新株予約権証券・TOKYO PRO MARKET など。売買の対象にならない |
| 株価10円未満 | 12 | 1〜数円の銘柄。1円の値動きで±50%を超える |
| 売買不成立の日が続いた後 | 4 | 売買停止などの後の再開日（例：55370 AlbaLink、92250 ブリッジコンサルティンググループ） |
| API の調整後の値でも同じ動き | 101 | 元データに実際にある値動き（TOB の発表・急騰など） |
| 分割の前後5日以内 | 0 | 調整漏れの疑いなし |
| API の値と食い違う | 0 | 調整の誤りの疑いなし |

**判断：** 分割・併合の調整漏れや、加工の誤りによるものは見つからなかった（「分割の前後」「API と食い違う」が 0件）。残りは実際の値動き、または購入の対象にならない銘柄なので、**データは修正しない。**

購入対象の銘柄で、その日に購入候補になり得たもの（流動性・データ条件を満たしていたもの）もある（例：65410 グレイステクノロジー 2022-02-04 +120%、30410 ビューティカダンホールディングス 2023-05-16 +112%、260A0 オルツ 2025-08-22 +140%）。件数の合計は、出力が途中で切れているため**未記録**（`quality_report.json` の `in_universe_count` と `in_universe_buy_eligible_that_day` で確認できる）。

## 4. 戦略の検討に回す観察（ChatGPT 側。設定は変更しない）

- **株価10円未満の低位株が購入候補に含まれる。** 流動性の条件（平均売買代金1億円以上）を満たせば対象になる。1円の値動きが±10%以上になるため、利確・損切りの水準（+10%・−5%）と呼値（1円）の関係が、他の銘柄と大きく違う
- **急騰（+100%超）した日に、購入候補の条件を満たす銘柄がある。** 高値ブレイクのシグナルが出る可能性がある。上場廃止やTOB などの特殊な事情を含むことがある
- どちらも、基準戦略の仕様（v0.2.0）では除外していない。**開発用期間の結果を見る前に**、扱いを変えるかどうかを決める必要がある（変える場合は仕様のバージョンを上げる）
