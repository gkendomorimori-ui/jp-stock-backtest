## 7. 件数のつながり（シグナル → 注文 → 購入 → 決済）

```
条件を満たしたシグナル                         1,391   （評価期間の最終日を除く 61 日分。うちシグナルがあった日 60 日）
├─ すでに保有中の銘柄のため無視                   19   （注文を作らない。orders.csv には記録されない）
└─ 注文候補                                    1,372
   ├─ 発注せず：株価が高く100株を買えない        681   （T 日の終値時点で判定）
   └─ 発注                                       691
      ├─ 取消：空き枠なし                         597   （T+1 の寄付で判定）
      ├─ 取消：資金不足（減額して0株）               1   （T+1 の寄付で判定）
      ├─ 取消：約定不可（売買不成立など）             0
      └─ 購入                                     93
         ├─ 決済済み                              93   （出口別内訳の合計と一致）
         └─ 未決済                                 0
```

- **681件（株価が高く100株を買えない）と 597件（空き枠なし）は重複しない。** 各シグナルは、次の順で最初に当てはまった理由1つだけに分類される
  1. T 日の終値時点：すでに保有中 → 無視（19件）
  2. T 日の終値時点：予算（総資産の20%）で100株を買えない → 発注しない（681件）
  3. T+1 の寄付：空き枠がない → 取消（597件）
  4. T+1 の寄付：売買が成立していない → 取消（0件）
  5. T+1 の寄付：減額しても0株 → 取消（1件）
  6. 上記以外 → 購入（93件）
  - このため、681件の中には「枠もなかった」シグナルも含まれうるが、その内訳は判定していない
- 注記：「資金不足」という言葉は、上の 5 の1件だけを指す。681件は資金全体の不足ではなく、**1銘柄あたりの予算（総資産の20%）に対して株価が高すぎる**ケース
- 19件（保有中の銘柄のシグナル）は、この実行の時点では orders.csv に記録されておらず、`signals`（1,391）と orders.csv の行数（1,372）の差から求めた。ログ補強後の再実行（13.3）で、orders.csv に `ignored_already_held` として **19件が直接記録され**、差し引きで求めた値と一致した
- シグナル 1,391 件と出口 93 件の差（1,298 件）は、上の分岐で購入に至らなかった件数（19 + 681 + 597 + 1）と一致する
- 評価期間の最終日（2026-07-03）のシグナルは、翌営業日がないため数えていない

## 10. データの対象範囲と制約

- データ：J-Quants API V2、Free プラン。約12週間遅れ。取得できるのは約2年分まで
- 対象：東証プライム・スタンダード・グロースの普通株（評価期間はすべて2022年4月以降なので、旧市場区分は含まれていない）。ETF・REIT・優先株などは除外
- 上場廃止銘柄：日ごとの銘柄マスタで判定しており、上場していた期間は対象に含む。この期間中、保有中の銘柄の上場廃止は起きなかった
- 株式分割・併合：調整後の値を、実際の値と調整係数から計算し直して使用（シグナルは調整後の値、約定・評価は実際の値）
- 配当：計上していない。ベンチマーク（TOPIX）は未取得
- 日足だけで判定しているため、日中の値動きの順序は分からない（同じ日に両方に届いた場合は損切り優先）
- 翌日の始値を見て株数を減らす処理は、バックテスト上の資金制約モデルであり、寄付成行注文を厳密に再現したものではない
- ストップ高・ストップ安の比例配分など、約定できない可能性は考慮していない
- **初期資金と100株単位の制約で、値がさ株はほぼ対象外になる**。結果は「株価がおよそ3,000円以下の銘柄」に偏っている
- 評価期間は約3か月（62営業日）と短く、特定の相場環境の影響を強く受けている可能性がある
